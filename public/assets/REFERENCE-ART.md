# Reference-derived artwork

This revision replaces the earlier independently generated scene on the Intro and AI Work chapters with artwork taken from the two 1672×941 reference images supplied by Teja. The user explicitly requested extracting the artwork and removing its surroundings.

## Masters and provenance

- `reference-intro-art.png`: 1672×760 chapter illustration, originally cropped from `Human curiosity, engineered impact.png` at `(0, 91, 1672, 851)`. The built-in imagegen editor recovered the quiet background and ribbons hidden by the reference headline, paragraph, buttons and project cards. The original source pixels were then restored everywhere outside those UI-removal masks, preserving the supplied portrait and visible ribbons. Thus this is a reference extraction with local recovered areas, not a newly designed portrait or ribbon. Decorative DATA/AI/PRODUCT annotations are preserved in the image.
- `reference-work-art.png`: direct unretouched 1381×379 crop of `From documents to usable data.png`, at `(291, 260, 1672, 639)`. This preserves the original documents, glass panel, ribbon, structured data diagram, output formats and illustrative annotations. It contains no website navigation or actionable UI.
- `reference-documents.png` and `reference-engine.png`: direct crops from the Work reference for a readable mobile stage layout.
- `reference-flow-bridge.png`: the built-in imagegen editor isolated/reconstructed the ribbon from the Work illustration for the Intro-to-Work transition. It is a reference-guided bridge, not a recovered pixel-exact mesh under the occluded objects.

High-quality WebP exports are served by the website. PNG masters are retained for reuse. Navigation, main headings, project selectors, descriptions, CTAs, teaser cards, dialogs and the assistant are HTML. The AI diagram's original illustrative lettering stays inside its raster artwork to retain the exact reference appearance; keyboard-accessible stage buttons and an image description expose its meaning. Other project tabs retain their own labels and diagrams.

At the reference viewport, the Work artwork's rendered bounds are exactly `(291,260,1381,379)`, covered by a browser regression check. A screenshot-region comparison against the supplied reference gave mean absolute RGB channel differences of approximately `(1.27,0.99,1.68)` out of 255, due to WebP encoding/browser output. This comparison is for the illustration region only, not a claim that every font glyph and page pixel is identical. Web fonts, interactive states, the assistant launcher and responsive adaptations still differ from the static reference.
